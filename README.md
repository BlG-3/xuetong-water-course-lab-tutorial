# 学习通水课作业和实验教程

这份教程记录的是一种电脑协作工作流：由使用者说明目标和材料，让 AI 助手通过 computer use 查看屏幕、操作本地文件和浏览器，协助整理课程实验报告并按要求提交到学习通。它不讲具体实验知识，也不包含任何人的身份信息、课程专属链接或作业原件。

## 工作流概览

1. 使用者把实验指导书、报告模板和相关材料放入一个清楚的本地文件夹，并在浏览器中登录自己的学习通账号。
2. 使用者告诉 AI 助手材料所在位置、需要完成的文件、格式要求和最终操作目标。
3. 助手先读取指导书和模板，整理任务清单，再逐项处理实验报告，保存到指定输出目录并按要求命名。
4. 使用者检查生成的报告和文件名。发现问题时，指出具体文件与修改要求，让助手修正。
5. 使用者明确要求提交后，助手通过浏览器逐项打开学习通作业、上传对应文件并提交；每次操作后都检查附件名称和提交状态。
6. 最后回到作业列表逐项核对结果。保留本地报告和提交状态记录，方便之后检查。

## 开始前准备

- 把指导书、空白报告模板和必要素材集中到一个目录，并确认文件能正常打开。
- 明确输出目录、报告命名规则、作业顺序、每项作业需要的附件格式和截止要求。
- 把需要填写的事实信息准备完整。只向助手提供完成任务确实需要的信息；公开教程、截图和仓库里用占位符，不放真实身份资料。
- 自己在浏览器中登录学习通并打开课程页面。不要把密码、验证码、Cookie 或带登录态的链接发给助手。
- 确认你有权使用该课程账号，并且最终提交内容经过本人检查。

## 给助手的提示词模板

把方括号中的内容换成自己的任务信息。不要把填入真实身份资料后的提示词公开分享。

```text
请使用 computer use 协助我处理学习通上的课程实验作业。

本地材料目录：[本地材料目录]
实验指导书：[指导书文件名]
报告模板：[模板文件名]
输出目录：[保存结果的目录]
需要完成的实验：[实验编号或作业列表]
文件命名规则：[课程要求的命名格式]
日期/时间等填写规则：[按实际课程要求填写；不同实验分别核对]

请先阅读指导书和模板，整理每项作业的要求，再按顺序完成报告并保存到输出目录。保留模板规定的栏目和顺序，不要编造实验数据或过程；遇到缺少的事实信息先列出需要我补充的项目。完成后检查文件内容、格式、实验编号和文件名，并告诉我各文件的保存位置。

我检查并确认文件后，请在我已登录的学习通页面中按列表顺序提交对应作业。每次提交前核对作业标题和附件文件名；提交后等待页面反馈，确认显示提交成功或等效状态，再处理下一项。最后返回作业列表逐项核对并汇报结果。遇到页面含义不清、需要重新登录或出现异常时先停下并告诉我。

隐私要求：只在课程提交所需的页面和本地文件中使用任务信息；不要把我的身份信息、课程专属链接、登录凭据或报告上传到公开仓库、公开页面或无关服务。
```

## 让 computer use 操作更可靠

computer use 是通过观察屏幕并与可见界面交互来完成任务。让助手按“观察—定位—操作—等待—核验”的节奏工作：先确认当前页面和作业标题，再选择对应控件；完成上传或提交后，检查页面显示的附件和状态。不要快速连续点击，也不要因页面暂时卡顿就重复上传。

把大任务拆成可检查的阶段会更稳妥：先读材料并列要求，再生成文件，然后由使用者检查，最后逐项提交。提示词里明确输入文件、输出位置、命名规则和验收条件，助手就更容易准确完成重复操作。

## 检查与隐私

- 抽查每份报告的实验编号、内容、图表、日期栏、文件名和可打开性。
- 提交前核对当前作业标题与附件；提交后检查页面状态，必要时重新打开作业确认附件仍在。
- 不要公开真实报告、成绩页面、姓名、学号、班级、私人路径、课程邀请码、会话链接或登录凭据。
- 分享提示词时，把本地路径、课程链接、账号资料和作业名称替换成通用占位符。
- 助手无法确认的实验事实应由使用者补充；不要把推测出来的数据当作真实结果提交。
