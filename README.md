# 学习通水课作业和实验教程

这是一份通用的课程作业与实验报告整理流程，重点介绍如何用浏览器和 computer use 完成重复、明确的页面操作。请根据课程要求独立完成实验内容；本教程不包含任何个人资料、账号信息、课程专属链接或作业文件。

## 一、准备材料

1. 打开课程页面，确认课程、作业名称、截止时间、提交格式和教师给出的要求。
2. 下载实验指导书、报告模板和必要的配套材料，确认文件可以正常打开。
3. 把每个实验的要求拆成清单：实验目的、任务内容、操作步骤、结果与分析、报告格式、提交方式。
4. 先确定本地工作目录，并使用容易辨认的文件名保存材料；不要把账号密码、登录链接或含个人信息的文件放进公开仓库。

## 二、阅读指导书并完成实验

1. 从头阅读指导书，标出每个实验的目标、输入条件、操作要求和验收结果。
2. 按实验编号逐项完成，不要只照抄模板。涉及代码或工具操作时，记录关键设置、实际输出、异常现象和修正过程。
3. 对照指导书检查结果。若结果与预期不同，先复现并排查，再在报告中如实说明原因和处理方式。
4. 保存必要的过程记录和结果截图。截图只保留能说明操作或结果的区域，提交或公开前检查是否露出姓名、学号、账号、课程密钥、个人路径等信息。

## 三、填写和检查实验报告

1. 使用课程提供的报告模板，保留规定的标题、栏目和顺序。
2. 在本地报告中填写课程要求的身份栏、实验日期、实验时间和教师栏；按各实验实际安排分别填写日期，不要把所有报告复制成同一天。
3. 报告主体写清目的、环境、步骤、结果、分析与结论。图片配简短说明，表格注明单位；避免只有截图而没有解释。
4. 逐份检查必填项、编号、日期、图表、代码格式和页面排版。确认文件可打开，导出的 PDF 或文档没有缺页、乱码或被截断。
5. 按课程规定命名文件，例如“学号姓名实验编号”；检查编号与报告内容对应。公开分享前另存一份去标识化副本，不能把含个人信息的作业报告上传到公开仓库。

## 四、在学习通提交作业

1. 在浏览器中登录自己的学习通账号，进入对应课程的作业或实验入口。
2. 按课程页面列出的顺序打开一项作业，先核对标题、说明、截止时间和提交要求。
3. 点击上传或添加附件，选择对应实验的最终文件。上传后检查页面显示的文件名和大小，确认没有选错草稿或其他实验。
4. 按页面要求填写说明并点击提交。若页面弹出二次确认，核对当前作业和附件后再确认。
5. 等待页面反馈，确认状态显示为已提交、待批阅或课程使用的等效状态；必要时重新打开作业查看附件是否仍在。
6. 返回作业列表核对该项状态，再按顺序处理下一项。全部完成后逐项复查，确保每个作业都提交成功。

## 五、computer use 操作要点

Computer use 是通过观察屏幕并操作界面来完成任务。可靠的基本循环是：

1. **观察**：读取当前页面和控件，确认课程、作业和当前步骤。
2. **定位**：根据可见标签、按钮文字或输入框提示选择目标，不凭印象点击相邻控件。
3. **操作**：一次完成一个明确动作，例如打开作业、选择文件或提交。
4. **等待**：给页面加载、上传或保存留出时间。
5. **核验**：查看页面状态、附件名称或成功提示，确认刚才的操作确实生效。
6. **继续或停止**：状态正确再进入下一项；页面含义不清、出现身份验证或异常提示时先停下来处理。

避免快速连续点击提交按钮，也不要在页面卡顿时重复上传。验证码、重新登录、权限确认等步骤应由账号持有人在页面中完成。不要把浏览器会话链接、Cookie、密码或验证码复制到教程、脚本、截图和公开仓库。

## 六、最终检查清单

- [ ] 实验内容逐项对照指导书完成，结果有解释
- [ ] 每份报告使用正确模板、实验编号和文件名
- [ ] 日期、时间和教师栏符合课程要求
- [ ] 文件可以打开，图片和页面没有错位或截断
- [ ] 上传的附件与当前作业对应
- [ ] 页面显示提交成功，作业列表状态已核对
- [ ] 公开材料已去掉姓名、学号、账号、私人链接和作业原件

## 隐私说明

本仓库适合分享通用操作流程、空白清单或去标识化示例。不要公开真实实验报告、成绩页面、个人身份信息、登录凭据、课程邀请码或带有会话参数的链接。提交作业时只使用本人有权访问的课程和账号。
